1. Acceptance of Terms

By accessing or operating the GridGuard SOC platform, control room operators, security engineers, and authorized personnel agree to be bound by these Terms and Conditions. This system is intended strictly for critical infrastructure telemetry forecasting, anomaly detection, and authorized cyber defense research.

2. Authorized Operational Use

Users are granted access solely to inspect smart grid load predictions, audit telemetry residuals, and execute controlled red-team threat simulations within the designated software environment.

  • Intended Operators: Utility dispatchers, SCADA security analysts, and energy system researchers.
  • Simulated vs. Production Controls: The interactive attack simulation module executes mathematical telemetry perturbations within the application memory. It must not be bridged directly to live generation breaker relays or high-voltage switchgear without secondary mechanical interlocks.
  • Prohibited Actions: Users must not attempt unauthorized reverse-engineering of baseline control algorithms or utilize the attack simulation scripts against external third-party energy networks.

3. Machine Learning Model Predictions & Disclaimers

GridGuard SOC utilizes HistGradientBoosting regression and Isolation Forest ensembles to provide automated predictive baselines and dynamic 3-Sigma thresholding.

While the models demonstrate verified empirical performance (e.g., 98.56% R-squared accuracy and 94.95% intrusion detection recall on benchmark holdout data), model outputs constitute decision-support recommendations. Grid operators maintain final operational authority for generator reserve dispatch and physical line de-energization.

4. Red Team Attack Injection Sandbox

The built-in attack injection suite (False Data Injection, IoT Botnet Surge, Energy Theft, and Telemetry Replay) is provided strictly for operator training, model threshold verification, and red-team readiness assessments. All attack payloads are localized and contained within the simulation framework.
