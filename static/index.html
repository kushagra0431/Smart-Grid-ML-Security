ML Architecture & Defense Pipeline

Three-layer cybersecurity defense: Predictive Baseline Forecaster → Residual Analysis → Unsupervised Anomaly Detection

NIST SP 800-82 Compliant
🧠

Layer 1: Predictive Baseline Forecaster

HistGradientBoosting Regressor (300 estimators) trained on 14,000+ hourly samples with 23 engineered features: lag variables (1h, 24h, 168h), cyclic sin/cos encodings, rolling statistics, and calendar indicators.

R² = 0.9856 | MAE = 362 MW
📐

Layer 2: Dynamic 3σ Residual Analysis

Computes absolute residuals |y_reported − ŷ_predicted| and triggers alarms when residuals exceed the training-calibrated 3.29σ boundary (99.9% confidence interval). Automatically adapts to seasonal grid patterns.

Threshold: ~1,057 MW | Confidence: 99.9%
🔍

Layer 3: Isolation Forest IDS

Unsupervised anomaly detector (150 trees, contamination=2%) trained on normalized residuals, load ratio, and rolling deviation features. Provides a continuous anomaly score for threat triage and prioritization.

AUC = 0.9793 | Recall = 94.95%
